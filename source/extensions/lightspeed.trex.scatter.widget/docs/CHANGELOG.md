# Changelog
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0]
### Added
- Created the Scatter window: paint/erase/flood controls, brush, placement, scale and target settings, the scatterable asset list with ingestion validation, an Assign Textures toggle with a per-asset Maps column and texture-set override, and brush presets
- Added a Scale Mode control to the SCALE section: Absolute Size gives each placement a height in stage units and shows a Size range, while Multiplier keeps the scale-factor range and its per-axis rows. The asset list reports each asset's measured height in the tooltip under its path
- Added a Prim Budget control to the TARGET section, which sets when the viewport's live stroke counter turns amber and red. The flood estimate no longer reports the flood cap as a prim total in Hit Surface mode, where the prototypes a flood lands on are only known once it runs: it reads `per instance` there and gives the multiplied total only for an anchor whose instances can be counted
- Added an Edit Selection Live toggle at the top of the PLACEMENT section, on by default, with a readout of what a settings change would update. With scatter selected, changing a placement, scale or seed setting updates that scatter as the control is dragged and commits as a single undo step, so a patch can be tuned after it was painted. Nothing outside the selection is touched, which is what keeps two patches painted with two presets on one mesh independent. The readout also reports the placements an edit left alone and why
- Added Turn X, Turn Y and Turn Z fields to the PLACEMENT section, showing the degrees the selected scatter has been turned by since it was selected. The viewport's rotate rings write them as they are dragged, and typing or dragging them turns the selection the same way, as one undo step. They are greyed out while nothing scattered is selected, and read zero again for a new selection. They are not brush settings: the Rotation ranges below them still decide what the next stroke paints, while a turn edits scatter that is already painted
- Added Base Rotation X, Y and Z to the PLACEMENT section and Max Surface Angle to the BRUSH section. Right after a stroke the live-edit readout says `Last stroke`, and changes apply to that stroke as part of it, so a test stroke can be tuned by eye and undone once while the settings stay. The Turn fields are greyed out on that stroke, which is tuned through the brush settings instead, and the pane now shares the live-edit driver of its context with the viewport gizmo
- Added Asset Up Axis rows at the top of the PLACEMENT section: one per palette asset, saying which axis its file authors and holding the Y-up/Z-up choice the brush stands it up by, flagged when the two disagree because the asset then lies on its side. Added a Reset to Defaults button beside Flood that puts every brush setting back to its default after a confirmation, keeping the asset list and the saved presets. The Apply To, Conform to Surface and Edit Selection Live help now describe painting on the selected mesh
- Added an OUTPUT section: an Instance Strokes toggle, Instance All and Split Selection buttons, and a count of the placements on the stage and how many of them are instanced. Selecting instanced scatter makes the live-edit readout say to split it before editing it
- A checkbox, combo box or preset change that re-applies to the selected scatter now always commits its undo step: the pane hands the change to the live-edit driver before finishing the edit, where the order the controller notified the two in used to decide whether the edit was committed or left open. The flood estimate and its confirmation now count what a flood will render, held to the limit a flood stops at, and ask when that is above the Prim Budget as well as when the cap is above the default; without an anchor the confirmation counts the instances of the selected meshes when Flood is clicked. The OUTPUT line reads as placements, meshes and rendered prims with thousands separators; undo and redo recount it and reset the Turn fields, and opening or closing a project clears the status line and the counts of the project before. The scale range rows are greyed out while Random Scale is off, Save As asks before replacing another preset of the same name, including one whose name differs only in case where the file system ignores it, and saves under the spelling that preset already has, picking a preset after one that was never saved removes that name from the list and enables Rename, Clone and Delete, and the tooltips of the BRUSH, PLACEMENT, SCALE and TARGET controls say what each one does to a stroke, including that Prim Budget is where a stroke turns amber and that five times it is where a stroke or a flood stops
